# 视觉参考文字说明

本目录不再提供二进制设计稿，以下文字来自原始参考图片的人工核对，用于指导布局、层级、间距和组件状态。整体风格为近黑背景、暖白色正文、金色强调和少量分隔线，标题使用衬线字体，正文使用无衬线字体，留白充足。

## 首页 `/`

桌面端顶栏居中偏窄，左侧是品牌字样，右侧是 Home、Work、About、Contact；当前项下方有金色短线。Hero 是大面积照片，人物靠右，左侧下半部叠放白色衬线姓名和两行简介。Hero 下边用一条金色水平线分隔，再显示“featured works”标题和三张横向作品卡片；卡片底部有作品标题与分类标签。页面以深色背景承托照片，不靠装饰图形堆叠。

## 作品集页 `/work`

桌面端顶部同样是品牌栏和导航。内容区左侧是一排胶囊筛选按钮，选中项为金色实底，未选中为深色描边。下方是多列 masonry 照片墙，照片高度随原始比例变化，列间留出较宽空隙。卡片悬停时照片上会出现半透明深色覆盖层，显示白色衬线标题、金色分类和“view”提示。

## 系列详情页 `/work/:seriesId`

首屏是一张横向系列封面，底部叠加大号衬线系列标题。正文采用窄栏加图片的交替节奏：一组图片配一段正文说明，下一组交换左右位置。系列摘要和引用句使用斜体衬线字体，与正文形成层次。每组图文之间用细金色水平线分段，滚动到后面仍保持宽松留白。

## 全局灯箱

打开灯箱后，背景照片墙整体压暗但仍可见。中间是一张按原始宽高比放大的照片，照片外框有细金色描边。左右两侧各一个大号箭头，右上角是关闭按钮。桌面端说明区位于照片下方或右侧信息带，显示衬线标题、分类和说明文字，不改变当前筛选结果。

## 关于页 `/about`

桌面端左侧是大幅竖版人物照片，右侧上半部是“about bio”标题、两段简介和一条带金色圆点的经历时间线；下半部是“contact”标题和 Name、Email、Message 三个下划线输入框，Send 按钮使用金色实底。整页仍然以照片和深色背景为主，不使用卡片式面板。

## 作品集页移动端 `/work`

宽度约 390px 时，顶部导航收成一个汉堡按钮。筛选胶囊允许横向排列。照片墙从多列 masonry 切换为单列，每张照片占满内容宽度，标题和分类放在图片下方。打开灯箱时，照片说明从桌面端侧边信息带改为贴在视口底部的一条说明区域，导航箭头仍保持在画面两侧。

以上说明只描述原始视觉结构，不要求逐像素还原；核心是暗色背景、照片主导、衬线标题、金色强调、宽松节奏和清晰的响应式状态。
